# Second Horizon - Threads Automation

> Build your second horizon, one system at a time.

## Overview

Second Horizon is a long-term project focused on building sustainable digital income streams through AI, automation, and content systems.

This repository contains the Threads automation platform powered by Cloudflare Workers and the official Threads API.

## Goals

- Automated Threads publishing
- AI-assisted content generation
- Content scheduling
- Analytics and logging
- Reliable deployment with GitHub + Cloudflare

## Tech Stack

- Cloudflare Workers
- Cloudflare KV
- GitHub
- Meta Threads API
- JavaScript (ES Modules)
